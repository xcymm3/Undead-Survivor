# Undead Tower 验收记录

## 定向跳跃、视角稳定与高阶尸群平衡（0.7.6，2026-09-05）

- 跳跃改为读取离地瞬间的 WASD，支持前后、侧向和斜向跳跃；未输入方向时原地跳，空中继续允许鼠标转向但不接受新的移动按键。
- 收紧 Pointer Lock 单事件位移与转角上限，过滤 Windows 光标回绕产生的中等幅度异常值，避免正常转向时突然大幅旋转。
- 第 10～12 波保留原四阶概率，并在整波未抽中时保底补入 1 只橄榄球僵尸。狂暴僵尸生命提升至 1200、半血狂暴阈值同步为 600；橄榄球僵尸总耐久提升至 3750，其中护甲 2000。
- 141 项单元测试、生产构建与 Electron 静默启动验收通过；发布由 `v0.7.6` 标签触发 GitHub Actions 构建并验收 Windows 便携版。

## 武器表现、尸群移动与波次平衡（0.7.5，2026-09-05）

- 消防斧改为红色纤维柄、单侧宽刃、背部尖镐和金属连接座，挥砍改为蓄力、快速斜劈、回收三段轨迹。自动霰弹枪改用缩放协调的枪身、护木、独立握把和深色鼓式弹匣，移除容易看成手部的方形弹药块。
- 十款武器右键抬起阻尼由 18 调整为 12，约 0.25 秒到达稳定瞄准位置；弹道、伤害和联机消息不变。无界面实机截图确认消防斧轮廓与自动霰弹枪比例正确。
- 僵尸移动增加 5 cm 身体起伏、7.5 cm 交替抬脚、约 15° 腿部摆动、约 9° 手臂摆动和轻微重心横移，水平方向仍严格对齐实际移动方向。
- 玩家每次受伤后获得 0.3 秒保护；清完每波时单机玩家和联机全队均恢复至 100 HP，阵亡队员继续在安全点复活。
- 第 1～12 波数量改为 9、15、21、27、33、39、44、49、53、57、61、64，之后每波增加 3 只。基础移速 2.5 m/s 封顶，刷新率每波增加 0.1 只/s并在 2 只/s封顶；第 7～12 波使用逐波平滑的阶位权重，第 12 波后保持最终构成。
- 139 项单元测试与生产构建通过；8 项无界面 Chrome 回归通过，覆盖十武器、右键抬枪、装填、跳河、完整清波、双客户端战斗、四人观战和全员复活。发布由 `v0.7.5` 标签触发 GitHub Actions 静默构建与验收 Windows 便携版。

## 十武器、右键抬枪与穿透攻击（0.7.4，2026-09-05）

- 新增项目内自制低多边形消防斧、喷火枪、自动霰弹枪和重机枪，与原有六款 Quaternius 动画枪组成十武器栏。数字键 1～9 与 0 分别选择第 1～10 件武器，每件保留独立弹量、射击和换弹动画。
- 消防斧使用 2.5 米近战扇形命中与无限耐久；喷火枪有效距离 15 米，能依次命中场景遮挡物之前的多只僵尸；自动霰弹枪每发 8 颗弹丸；重机枪使用 120 发弹箱。联机仍只发送武器、开火和视角状态，命中由房主判定。
- 全部十武器支持按住右键抬起；步枪、狙击枪、自动霰弹枪和重机枪的枪身及机械瞄具对准准星。该动作只改变第一人称武器模型，不改变准星、相机、腰射枪口、散布、伤害或联机带宽。
- 平衡评估结果写入 `weapon-balance-results.json`。重机枪射击间隔最终调为 0.09 秒，综合换弹的理论持续输出为 312.3；自动霰弹枪理想全弹丸命中为 328.2；喷火枪单目标为 128.6，以穿透多目标补偿；消防斧为 235.3，以近距离风险换取无弹药消耗。
- 128 项单元测试和生产构建通过。真实浏览器中，十武器切换、右键动画、换弹与半自动输入共 2 项通过；双客户端开房、射击清波、后台房主模拟、观战和全员阵亡结算通过。测试均无界面运行。

## 障碍寻路与两秒失败特写（2026-09-04，仅源码/网页版）

- 移除金色/红色圆弧、刻度、红框及精确剩余距离；仅保留接近哨塔的文字提醒。内部仍连续检测 8 米失败半径，首次突破立即冻结成绩和战斗。
- 新增两秒失败阶段：武器和战斗 HUD 隐藏、镜头推进、突破者受光增强并伸臂扑击、其他僵尸压暗、播放低沉失败声；随后自动显示结算和本机排行榜。失败阶段不能射击、装填或按 Esc 恢复；重开恢复原机位与 61° 视野。
- 186 个实体障碍与实际场景模型共用占地数据。0.65 米静态导航栅格、0.95 米身体留白，涵盖车辆、建筑、路障、围栏、树干、岩石和门柱。直路优先，受阻绕行；出生点修正到可达区域，拥挤避让也受连续障碍碰撞约束。
- 单元测试覆盖长线段穿越薄围栏、拥挤绕障、通路直行、高速移动、实际八区域两轮入口均可到达。特写额外检查左右各 75°、每 5° 一处的取景，实际扑击模型的头部和胸部不被哨塔挡住。
- 两秒流程在浏览器页面内部逐帧采样，记录首帧、中段、结束、突破者 ID 与输入锁定，避免跨进程读取耗时错过短动画。坚守时长、位置、血量和射击数在特写期间不变；动画结束才显示结果。
- 声音测试确认失败声停止 BGM、经过统一主音量，静音时不创建音源。音量浏览器断言等待 Web Audio 参数生效，不再依赖点击后立即同步读取。
- 最终 70 项单元测试和生产构建通过。16 个浏览器流程均完成验证：全量回归中 15 项通过，失败流程改为页面内采样后单独通过；取景遮挡修正后再次通过该真实对局流程（34.1 秒），包括移动击杀、两秒特写、自动结算、纪录保存、重开镜头复位和刷新后读取排行榜。浏览器全程单 worker。
- 已查看实际对局、特写及排行榜截图。特写图从动画中段的 WebGL 画布截取，因此不包含页面上的“防线失守”和突破者文字；游戏实际播放时仍显示这些提示。EXE 未重新打包，SHA-256 保持 `b9595a032f4cdd11ba4f8814fd3cc1601bd0d6c68870ed35fae3c6a7767de6a1`。

# M0 历史验收（0.1.0）

## 手动验收步骤

1. 运行 `npm run dev`，打开 5175 端口，看到 Undead Tower 标题页和灰松哨站。
2. 进入哨站，检查右手、袖口、枪身与枪口在第一人称画面中可见。
3. 移动鼠标到画面左右和上下；准星应立即跟随，枪口转向准星，环境缓慢小幅转动。
4. 连续左右甩鼠标，停在屏幕边缘；镜头不能超过水平 ±4°、垂直 ±2.5°，不能转身看向身后。
5. 点击左键，弹药减少，枪口产生短促火光，伴随曳光、抛壳、后坐平移和枪声；按住左键可连发。
6. 射击人形靶的胸部和头部，检查命中提示与击倒；靶标应在 3 秒后重新站立。
7. 按 R 换弹，装填期间不能射击；完成后弹匣恢复 30 发。打空后不能凭空继续射击。
8. 按 Esc 暂停，点击空白处不增加射击数；按 Esc 继续。窗口失焦或切换标签页也应暂停。
9. 设置中调整镜头阻尼、静音、粗颗粒像素；设置按钮不会触发开枪。关闭设置后恢复此前的暂停/游玩状态。
10. 从暂停菜单重新开始，射击统计、命中数、靶标生命和弹药都应复位。
