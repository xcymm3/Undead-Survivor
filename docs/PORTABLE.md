# Undead Survivor Windows 便携版

成品：`release/Undead Survivor-0.5.0.exe`，面向 Windows 10/11 x64。按用户要求于 2026-09-04 从当前源码打包，包含 WASD 自由移动、自由视角、空格跳跃、中央弯曲河流和两座桥、波次刷怪、100 点生命及波数排行榜。

## 使用

将 EXE 放在可写入的文件夹，双击启动。无需安装 Node.js、Chrome，也不需要启动本地服务器，可以离线游玩。首次启动会解压内置运行环境到临时目录，需要稍等片刻。

- WASD 移动，鼠标转向，左键开火，空格跳跃。
- R 换弹，数字键 1–6 或滚轮切换枪械。
- Esc 释放鼠标并暂停，M 静音，F11 或右上角按钮切换全屏。
- 僵尸只能走桥；玩家可以跳过河流，落水立即失败。
- 每波数量依次为 9、15、21……；首波移速 1.4 m/s，每波增加 0.15 m/s。清波后休整 5 秒，排行榜按已清完波数计分。

EXE 旁自动创建 `Undead Survivor Data`，保存排行榜、音量设置和缓存。搬迁时将 **EXE 与数据文件夹一起拷贝**。便携版与网页版的成绩独立；波次榜也不会混入旧时长榜。

只需分发这一份 EXE，不需要 `win-unpacked` 目录；不要把个人数据文件夹混入发给其他玩家的游戏包。成品未做 Authenticode 签名，不要求管理员权限。

文件名统一采用 `Undead Survivor-版本号.exe`。图标为绿色盾形背景上的持枪幸存者，源码在 `desktop/icon.svg`；`desktop/icon.ico` 包含 16–256 像素的七种尺寸，网页 favicon 使用相同图案。

## 重新打包与验证

```powershell
npm ci
npm run dist:portable
npm run test:portable
```

安装运行环境时使用 Electron 官方安装器并校验包内哈希。`electron-builder.cjs` 生成 Windows x64 单文件便携版，不自动发布。EXE 放在 `release/`，二进制不提交到 Git。

成品测试使用 `test-results/portable-时间戳/` 中的独立副本，验证离线加载、鼠标捕获、跳跃、六枪开火换弹、切枪、暂停、全屏、首波 9 只、攻击致死与两秒特写、波数结算。关闭后将测试 EXE 连同数据移入同一测试目录下的新位置，再启动核对排行榜和音量设置。测试不向交付 EXE 旁写入测试成绩。

## 桌面实现

入口为 `desktop/main.cjs`，私有 `undead://game/` 协议直接读取包内资源，无 HTTP 服务或端口依赖。启用沙箱、上下文隔离与内容安全策略，不向页面开放 Node API，生产包不包含游戏诊断接口。正常双击启动不开调试端口；只有成品验证时临时启用本机调试连接。

日常开发仍默认只改源码和网页版，用户明确要求后才重新打包 EXE。
