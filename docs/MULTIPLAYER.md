# Undead Survivor 0.6.0 EXE 联机说明

这份说明适用于 `Undead Survivor-0.6.0.exe`（Windows 10/11，64 位）。该版本包含 Steam 双人协作；旧的 0.5.0 EXE 只有单人模式。

## 发给朋友哪些文件

将 **Undead Survivor-0.6.0.exe** 和 **联机说明-0.6.0.txt** 一起发给朋友即可。游戏所需的运行环境、Steam 接口与原生 DLL 已装在 EXE 内，无需安装 Node.js、下载项目源码或执行命令。

双方使用同一份 0.6.0 成品。不要发送 `Undead Survivor Data`，这是你自己的设置、成绩与缓存。也不需要发送 `win-unpacked` 文件夹。

## 开始前准备

- 两台 Windows 64 位电脑，分别登录 **两个不同的 Steam 账号**。一个账号在本机开两份游戏不能代替双人联机。
- 双方安装并运行 Steam，保持登录和联网，然后再启动游戏。
- 将 EXE 放在可写入的普通文件夹，例如 `D:\Games\Undead Survivor`；不要直接在压缩包内运行。
- 本版使用 **Spacewar（App ID 480）** 做开发联机测试。Steam 可能显示 Spacewar，这是当前测试身份；本游戏尚未使用自己的正式 Steam App ID。

直接双击 EXE 即可，首次解压稍等片刻。无需手动运行 Spacewar、配置 Steam API Key 或新建 `steam_appid.txt`，本程序会显式传入 480。Steam 客户端必须能够初始化该测试 App ID；如出现 Steam 未就绪，请按下方排查。

## 两个人怎么进入同一局

1. 双方双击 `Undead Survivor-0.6.0.exe`，在首页点击 **多人模式**。
2. 房主填写容易辨认的房间名称，点击 **创建房间**，停留在房间内等待。
3. 队友点击 **搜索房间**，找到该名称后点击 **加入房间**。如果列表暂时没有出现，重新搜索；也可以让房主把界面上的完整数字房间号发给队友，队友填入后点击 **按房间号加入**。
4. 房间显示 **2 / 2 人** 后，由房主点击 **开始双人游戏**。队友无需另外点击单人模式，双方连接完成后一起进入战斗。
5. 开局后移动鼠标瞄准、按左键射击。鼠标没有被捕获时，点击游戏画面；按 Esc 可以释放鼠标。

房间最多两人，已经开始的对局不能中途加入。房间是公开测试房间；使用容易辨认的名称并核对加入者。若需要重新开局，退出原房间后由一人重新创建。

## 操作与合作规则

| 操作 | 功能 |
| --- | --- |
| WASD | 移动 |
| 鼠标移动 / 左键 | 转向瞄准 / 射击 |
| 空格 | 跳跃，可跨越河流 |
| R | 换弹 |
| 1–6 / 鼠标滚轮 | 切枪 |
| Esc | 释放鼠标、打开菜单；联机对局继续 |
| M | 静音 / 恢复声音 |
| F11 / 右上角全屏按钮 | 切换全屏 |

- 两名玩家各有 **100 点生命**。僵尸追击最近的存活玩家，挥臂攻击后扣血。
- 中间有弯曲河流和两座桥。僵尸只能走桥；玩家可以跳河，落入水中立即阵亡。
- **一个人阵亡后观战队友，两个人都阵亡才结束。** 本局不复活，观战者不能继续移动或开枪。
- 首波 9 只，之后每波增加 6 只；僵尸逐波加速。整波全部消灭后休整 5 秒，进入下一波。
- 合作目标是清完更多波；第 3 波中途全灭表示已完成 2 波。双人成绩显示在结算页，**不写入单人排行榜**。
- 打开菜单、切换窗口都不会暂停联机战斗。任意一方离开、关闭游戏或连接超时，本局中止，需要重新创建房间；目前没有断线续局或房主转移。

## 常见情况

**显示“Steam 未就绪”**

确认 Steam 已启动、已登录且能联网。Steam 和游戏应在同一个 Windows 用户下运行，通常都正常双击即可，不要一个以管理员运行、另一个普通运行。登录完成后点击游戏里的“重新连接 Steam”；仍失败则退出游戏，保持 Steam 开启，再双击 EXE。把完整错误文字发给开发者，便于区分 Steam 初始化失败和文件缺失。

**搜索不到朋友的房间**

先核对双方都是 0.6.0、房主仍在房间里等待、房间未满且尚未开始。重新搜索，或使用完整数字房间号加入。搜索只展示本游戏协议兼容的可加入房间，不展示共用 Spacewar 的其他项目房间。

**加入成功但无法开局，或对局掉线**

确认双方 Steam 均保持登录，网络未中断；如果防火墙询问网络访问，请允许这份游戏与 Steam 在你使用的网络上通信。退出房间再重新创建。持续失败时，请记录双方版本、错误提示、卡在创建/加入/开局哪一步，以及是否使用不同网络。

**没有 Steam 能玩吗**

可以玩练习模式和单人正式模式，单人资源全部在 EXE 内，可离线运行。多人模式需要 Steam 和网络。

**换目录后设置、成绩去哪了**

EXE 旁的 `Undead Survivor Data` 保存本机设置、单人排行榜和缓存。迁移自己的游戏时，把 EXE 和这个文件夹一起移动；给朋友时只发 EXE 和说明。旧版升级可将新版 EXE 放在原文件夹中，沿用该数据目录；不要同时运行两个版本。

## 这版验证到了哪里

本版是供朋友之间测试的联机版本。已用本机无界面双客户端测试验证创建/搜索/加入、双方开枪清波、单人阵亡观战及全员阵亡结算。EXE 成品另外执行隐藏、不可聚焦、静音的启动与依赖检查。

**目前只有一台电脑或一个 Steam 账号，尚未完成两台电脑、两个不同 Steam 账号之间的实际 Spacewar 联网验收。** 本地双客户端测试使用测试通道，不能保证所有网络环境下都已验证通过。

拿到第二台电脑和第二个账号后，建议首次一起检查：能找到房间 → 两人同时开局 → 彼此能看到移动、跳跃和开枪 → 一起杀掉同一批僵尸并升波 → 一人阵亡后另一人继续 → 两人都阵亡后同步结算。最后再检查一人离开时另一端是否收到中止提示。

开发参考：[Steam 官方 Spacewar 示例](https://partner.steamgames.com/doc/sdk/api/example)、[Steam 初始化条件](https://partner.steamgames.com/doc/api/steam_api#SteamAPI_Init)。
