# Undead Survivor 0.7.0 EXE 联机说明

这份说明适用于 GitHub Release 中的 `Undead-Survivor-0.7.0.exe`（Windows 10/11，64 位）。该版本使用 Steam Spacewar（App ID 480）测试 2～4 人 P2P 协作。

## 发给朋友哪些文件

从 GitHub Release 下载并发送以下两个文件：

- `Undead-Survivor-0.7.0.exe`
- `Multiplayer-Guide-0.7.0.txt`

所有玩家必须使用相同版本。游戏已包含 Electron、Steam 接口与原生 DLL，无需安装 Node.js，也不要发送 `Undead Survivor Data` 或 `win-unpacked` 文件夹。

## 开始前准备

- 每名玩家各使用一台 Windows 64 位电脑和一个不同的 Steam 账号。
- 所有电脑先启动 Steam、完成登录并保持联网，然后再启动游戏。
- 将 EXE 放在可写入的普通文件夹，不要直接在压缩包内运行。
- Steam 显示 Spacewar 属于当前测试身份，无需手动安装或启动 Spacewar，也无需配置 API Key。

## 创建并开始房间

1. 所有人双击同一版本的 EXE，在首页点击 **多人模式**。
2. 房主填写房间名称并点击 **创建房间**。
3. 其他玩家搜索房间后加入，也可以输入房主提供的完整数字房间号。
4. 房间达到 2 人后，房主可以直接开始，也可以继续等待，最多 4 人。
5. 房主点击 **开始多人游戏**。所有成员完成握手后会同时进入战斗。

已经开始的房间不能中途加入。成员在加载或握手阶段离开会中止本次开局；重新进入大厅后创建新房间即可。

## 操作与合作规则

| 操作 | 功能 |
| --- | --- |
| WASD | 移动 |
| 鼠标移动 / 左键 | 转向瞄准 / 射击 |
| 空格 | 跳跃，可跨越河流 |
| R | 换弹 |
| 1–6 / 鼠标滚轮 | 切枪 |
| Esc | 释放鼠标并打开菜单；联机战斗不会暂停 |
| M | 静音 / 恢复声音 |
| F11 / 右上角全屏按钮 | 切换全屏 |

- 每名玩家拥有 100 HP，僵尸追击最近的存活玩家。
- 玩家阵亡后进入第一人称观战。鼠标被游戏捕获时，点击左键依次切换存活队友。
- 清完当前波次后，所有玩家恢复至 100 HP；阵亡玩家会在安全出生点复活并恢复控制。
- 只有全队在同一波内全部阵亡，对局才会结束。
- 僵尸不能跳跃，只能经桥过河。玩家可以跳河，落在水中会立即阵亡。
- 多人成绩不写入本机单人排行榜。

## 画质和流畅度

每台电脑的画质设置相互独立，房主设置不会改变队员画面。客机可以在右上角设置中选择极致性能、性能、平衡、画质或极致画质，并继续调整渲染比例、抗锯齿、阴影、特效、视距和帧率上限。

4K 显示器若需要最清晰画面，应使用 100% 渲染比例；显卡压力较大时先选择“画质”或“平衡”。Windows 缩放、窗口分辨率和显卡硬件加速状态也会影响清晰度。网络状态面板中的延迟和快照信息可用于区分网络波动与本机帧率不足。

## 常见情况

**显示“Steam 未就绪”**

确认 Steam 已启动、登录且能联网。Steam 和游戏应在同一 Windows 用户权限下运行。保持 Steam 开启，退出并重新启动游戏；仍失败时记录完整错误信息。

**搜索不到房间**

确认所有人都使用 0.7.0，房间尚未开始且人数少于 4。重新搜索或使用完整数字房间号加入。不同联机协议版本不会互相显示。

**移动被拉回或僵尸瞬移**

先查看本机 FPS 和联机延迟。降低客机画质不能改善网络延迟，但可以避免本机掉帧放大同步卡顿。持续发生时记录双方网络类型、延迟、丢包表现和是否使用无线网络。

**换目录后设置和成绩不见了**

EXE 旁的 `Undead Survivor Data` 保存本机画质、音量、单人排行榜和缓存。迁移自己的游戏时同时移动该目录；发给其他玩家时不要附带个人数据。

## 当前验收范围

源码已通过四名玩家输入隔离、四人 Steam 握手、多人观战切换、波次复活、双客户端完整战斗和单机跳河回归测试。便携版在 GitHub Actions 中执行隐藏、不可聚焦、静音的冷启动，检查原生 Steam DLL、离线资源、中文路径搬迁和设置保存。

0.6.0 已进行双机双账号试玩。0.7.0 新增的三人、四人组合仍建议分别实机检查：全员同时开局、彼此移动和射击、轮流观战、清波复活、全员阵亡结算，以及成员离开后的中止提示。
