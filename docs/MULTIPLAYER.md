# Steam 双人协作测试

本次交付为源码改动，不更新 `release/Undead Survivor-0.5.0.exe`，版本号仍保留 0.5.0。已有 EXE 不包含这次联机功能。

## 启动与加入

1. 两台 Windows x64 电脑分别登录两个不同的 Steam 账号，使用相同版本的项目源码。
2. 在各自的项目目录执行 `npm ci`，然后执行 `npm run desktop`。该命令只构建网页并用开发运行时启动桌面窗口，不生成 portable EXE。
3. 在首页选择「多人模式」。一人输入名称并创建房间，另一人点击搜索并加入，也可以输入房间号。
4. 房间满两人后，由房主点击「开始双人游戏」。双方握手成功后进入同一局。
5. WASD 移动，空格跳跃，鼠标瞄准、左键开火，R 换弹，1–6 或滚轮切枪。

浏览器 `npm run dev` 保留单人玩法并显示桌面版提示。未登录 Steam 时，桌面版显示连接失败提示，可登录后重试。

开发测试使用 Steam 官方示例 App ID **480（Spacewar）**。所有房间写入项目与协议标识，搜索在 Steam 服务端筛选，避免混入共用 480 的其他游戏房间。它不是本游戏的正式发行 App ID。

## 对局规则

- 两名玩家各有 100 点血量，僵尸追击距离最近的存活玩家，攻击先挥臂，再扣血；目标死亡后改追另一人。
- 玩家可以跳跃过河，僵尸仍只能走两座桥。落水只使该玩家阵亡。
- 单人阵亡后摄像机跟随存活队友，仍可转动视角；阵亡者不能移动、射击或切换武器。本局不复活。
- 两人都死亡才结算共同守住的波数与击杀。双人结果不写入单人排行榜。
- 仍沿用原来的六款枪、伤害、护甲、每波配额、移速增长和五秒休整；刷怪点距离所有存活玩家至少八米，并位于选定存活目标的前方。
- Esc 打开菜单、切出窗口不会暂停联机对局；后台保留模拟与网络更新，停止绘制。单人暂停规则不变。
- 任意一方离开、关闭游戏或连接超时，中止本次联机对局并提示重连；不做房主迁移。结算后返回多人大厅可重新创建房间。

## 实现与验证范围

Electron 主进程通过 `steamworks.js` 初始化 Steam，管理两人大厅及可靠 P2P 数据包。少量 Steam DLL 接口通过 Koffi 提供大厅查询过滤和关闭 P2P 会话。渲染页面通过隔离的 preload 接口调用固定联机动作，不直接获得 Node.js 或 Steam SDK。

房主权威模拟两名玩家、僵尸、伤害和波次，每秒发送十次场景快照。队友每秒发送二十次移动输入及离散跳跃、开火、换弹、切枪命令；移动做本地预测与位置纠正。消息包含房间、协议和对局标识，仅接受当前成员；输入与快照检查数值边界和递增序号。

测试命令：

```sh
npm test
npm run build
npx playwright test tests/e2e/coop.spec.ts
npm run test:desktop
```

单元测试覆盖房间握手、非房主拒绝开局、无效/过期包、超时清理、跳跃、落水、独立生命和全员死亡。双端浏览器测试通过仅在测试内注入的本地通道运行真实 React UI 和战斗模拟，检查双方射击、共同清波、观战与结算；该通道不进入生产代码。

桌面冒烟测试默认以 `--silent` 启动隐藏、不可聚焦、不占任务栏、静音的 Electron 开发运行时；操作使用页面 DOM，截图使用 `stayHidden`，不会显示或激活窗口。测试验证隔离的 preload 接口、480 配置、未登录 Steam 的提示与返回首页，不打开或修改已有便携 EXE。单独后台启动可用 `npm run desktop:silent`。浏览器自动测试明确使用 headless 和静音。

当前只有一台电脑或一个 Steam 账号，因此**尚未完成两台电脑、两个 Steam 账号之间的 Spacewar 实际联网验收**。Steam NAT 穿透、网络延迟下的手感、不同网络环境的连接成功率，必须在具备第二台设备及第二个账号后检查。

正式两端验收应检查：搜索/房间号加入、同时开局、双方移动跳跃与开枪、两端同一只僵尸死亡、完整升波、单人死亡后继续、全员死亡结算，以及退出 Steam/断网后的提示。

## 本机验收记录（2026-09-04）

- 92 项单元测试通过，包含延迟射击不覆盖最新移动朝向，以及静默启动、重复启动不抢焦点、启动失败不弹窗。
- 两项无界面联机端到端测试通过：创建/搜索/加入、房主开局、双方射击清完一波、后台继续模拟但停止绘图、后台换弹/切枪、单人阵亡观战、全员阵亡同步结算、无单人榜写入。
- 两个测试页面共用一个无界面浏览器，交接控制时先释放另一页的鼠标锁；不激活用户的桌面窗口。
- 实际 Electron 静默冒烟测试通过，检查窗口不可见、未聚焦、不可聚焦且静音；当前 Steam 未登录，480 配置及失败提示正常。
- TypeScript 和网页生产构建通过。保留此前单人回归结果；本轮没有运行便携版，也没有重新打包 EXE。

以上本地双端测试使用测试通道，不能替代上文所述的两账号 Steam 实际联网验收。
