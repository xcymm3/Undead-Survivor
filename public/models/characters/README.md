Retrieved 2026-09-05. This project includes six original glTF character files:
Casual Male/Female, Soldier Male/Female, and Worker Male/Female.

The game clones the original skinned models at runtime, applies a selectable
primary/accent material palette, and plays the bundled animations. The source
models are otherwise preserved. Models are served locally with the game.
